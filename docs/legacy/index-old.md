# ROS2 LLM Bridge

Welcome to the documentation for the `ros2_llm_bridge` project!

This project provides a critical bridge between a Large Language Model (LLM) and a real robotic hardware platform (Yahboom Rosmaster X3 Plus). It connects high-level semantic instructions generated by an AI with the low-level ROS 2 actions and hardware APIs needed to execute them.

## General Functioning

The system is composed of several key components:

1. **Hardware Service (`hardware_service.py`)**:
   A standalone Python server that communicates directly with the foundational robotic hardware layers (e.g., `Rosmaster_Lib`) and the cameras (`OpenCV`). It manages safe velocity clamping, obstacle detection (via ultrasonic sensors), servomotors, the robotic arm, and captures camera frames.

2. **ROS 2 LLM Bridge Node (`bridge_node.py`)**:
   The core ROS 2 node. It handles the ROS 2 lifecycle and acts as the async client interacting with the *Hardware Service*. It can publish directly to ROS 2 topics (like `/cmd_vel`) or delegate complex tasks to the hardware service.

3. **API Server (`api_server.py`)**:
   A FastAPI application running alongside the ROS 2 node. It exposes REST endpoints (like `/execute_action`) that an external LLM agent uses to trigger actions on the robot.

4. **Action Handler (`action_handler.py`)**:
   Responsible for interpreting and routing the structured commands received from the API layer to the corresponding async methods on the ROS 2 node.
