## 5 ter. Voie de la copie patchée : moteur produit, chargement bloqué

Copie `/home/jetson/software/yolov5-7.0-trt10` (hors dépôt), patch versionné dans
`deploy/patches/yolov5-7.0-tensorrt10.patch` (26 lignes, deux changements d'API TensorRT 10) :

1. `config.max_workspace_size = …` → `config.set_memory_pool_limit(trt.MemoryPoolType.WORKSPACE, …)`
2. `builder.build_engine(network, config)` → `builder.build_serialized_network(network, config)`
   puis écriture directe du tampon sérialisé.

Résultat de l'export :

```
ONNX: export success ✅ 1.7s, saved as yolov5s.onnx (14.0 MB)
TensorRT: building FP16 engine as yolov5s.engine
TensorRT: export success ✅ 530.8s, saved as yolov5s.engine (17.0 MB)
```

Moteur copié en `/home/jetson/models/yolov5s_fp16.engine` (hors git).

**Blocage au chargement**, dans le runtime de yolov5 7.0 :

```
File "/home/jetson/software/yolov5-7.0/models/common.py", line 404, in __init__
    for i in range(model.num_bindings):
AttributeError: 'tensorrt.tensorrt.ICudaEngine' object has no attribute 'num_bindings'
```

TensorRT 10 remplace toute l'API de bindings (`num_bindings` → `num_io_tensors`,
`get_binding_shape` → `get_tensor_shape`, `set_binding_shape` → `set_input_shape`,
`execute_v2` → `execute_async_v3`). Porter `models/common.py` de yolov5 7.0 est une réécriture,
pas un correctif d'une ligne : je m'arrête là, conformément à la consigne (« si l'export échoue
encore, tu t'arrêtes avec l'erreur exacte »).

Second point relevé : `models` est déjà chargé depuis le dépôt **original** par
`torch.hub.load` du backend torch au moment où le backend moteur ajoute la copie à `sys.path` ;
même patchée, `models.common` resterait celle de l'original dans le processus du nœud. Le backend
moteur devra soit importer avant tout `torch.hub.load`, soit exécuter l'inférence avec sa propre
implémentation TensorRT (`num_io_tensors`).

**Conclusion P12** : le nœud est livré, publié et mesuré (4,98 Hz, p50 47 ms, RSS 1 418 Mo,
`GR3D_FREQ` 99 % sous charge). Le moteur FP16 est produit et reproductible (patch versionné), mais
**non chargé** : ligne « moteur TensorRT » du tableau = *exporté, non chargé*.
