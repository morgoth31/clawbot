## 4. Écart au référentiel : le SDK MCP installé est la version 2

Le §9 prescrit `FastMCP`. Le SDK installé est **mcp 2.3.0**, où `FastMCP` a été renommé
`MCPServer` (`from mcp.server.mcpserver import MCPServer`). `serveur.py` charge `MCPServer` et
retombe sur `FastMCP` si la version 1 est présente. Deux conséquences constatées :

1. `MCPServer` **refuse** les paramètres de fonction commençant par `_` : la première version du
   serveur (fabrique générique `*args, **kwargs`) a été rejetée à l'enregistrement.
2. Les 12 outils sont donc déclarés **un par un avec leur signature explicite** — ce qui est aussi
   la bonne réponse au besoin de schéma : un `**kwargs` n'aurait donné au LLM aucun paramètre.
