## 5. API 8000 (REQ-OPS-043)

`bridge_node.cpp` ne crée plus aucun éditeur `Twist`. `SetVelocity` devient un skill
`move_relative` (ou `rotate` si la rotation domine), `Stop` devient le skill `stop`,
`NavigateTo` devient `navigate_to` — donc un refus `CAPABILITY_INACTIVE` tant que Nav2
n'est pas servi, au lieu d'une navigation à l'estime. Les trois passent par
`/clawbot/execute_skill` et rendent la main immédiatement (« transmis à l'exécutif ») :
le suivi se fait sur `/clawbot/mission/events`, pas sur le future du goal (leçon P09).
Compilation vérifiée (`colcon build --packages-select ros2_llm_bridge_cpp`, code 0).
